Электронные оперативные планы тушения пожаров

Подключение к Supabase

Вставьте только Project URL и Publishable key (или anon public key). Настройте их один раз для публикации. Для постоянной настройки заполните файл config.js один раз. Если он не заполнен, введите параметры здесь. Секретные ключи сюда вводить нельзя.

Вход администратора

Планы загружаются из Supabase. Для работы нужен интернет. Достоверность оперативных данных необходимо проверить перед применением.

Пожарные подразделения ДЧС СКО

Загрузить папку с готовыми ОПТП

Можно выбрать папку одного объекта (например, Театр кукол / ОПТП.docx и Театр кукол / Поэтажные планы / Этаж 1.jpg) или общую папку подразделения с несколькими папками объектов. Сведения из DOCX распределяются по вкладкам, а PDF и изображения генплана, зерносушилок, технологических схем, чердака, подвала и этажей — в «Поэтажные планы». Схемы водоснабжения останутся в отдельной вкладке. Перед сохранением проверьте названия объектов и распознанные данные. Старые .doc и сканы сохраняются как файлы без извлечения текста. До 200 файлов за одну загрузку, каждый до 20 МБ.
