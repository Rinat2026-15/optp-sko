# ОПТП СКО — загрузка готовой папки Word и поэтажных планов

Выберите карточку пожарного подразделения, войдите как администратор и откройте «Загрузить папку с готовыми ОПТП».

## Структура папки

```text
СПЧ-1/
  Театр кукол/
    ОПТП.docx
    Поэтажные планы/
      Этаж 1.jpg
      Этаж 2.pdf
  Школа №1/
    ОПТП.docx
    Поэтажные планы/
      Этаж 1.png
      Этаж 2.png
```

Приложение создаёт карточку по названию папки объекта, прикрепляет Word и PDF, распределяет этажные схемы по существующей вкладке «Поэтажные планы» с переключением и масштабированием. В рамках DOCX автоматически распознаёт только явно обозначенные поля: адрес, район, этажность, высоту, характеристики объекта, противопожарное водоснабжение, эвакуацию и силы и средства. Перед загрузкой откройте предварительный просмотр и проверьте значения; уже заполненные поля не изменяются. Неопознанные сведения остаются в оригинальном Word.

Форматы: DOCX для извлечения текста, DOC/PDF для хранения, PDF/JPG/PNG для поэтажных схем. Старые DOC, сканы, изображения текста и PDF с текстом не обрабатываются как структурированные сведения, но загружаются как документы/схемы. Не более 200 файлов за раз, до 20 МБ каждый.

Метка номера этажа определяется по имени файла («1 этаж», «Этаж 2»). Без номера файл остаётся схемой с пустым номером этажа. Для основной информации желательно использовать наименования разделов: «Общие сведения», «Водоснабжение», «Силы и средства», «Эвакуация».

## Однократная настройка

Если нужно, чтобы извлечённая информация о **силах и средствах** отображалась текстом в соответствующей вкладке, выполните SQL из `supabase/migrations/202611060003_forces_and_means.sql`. Без него оригинальный Word и остальные поддерживаемые поля загружаются, но текст этого раздела не сохраняется отдельно.

Для чтения DOCX в браузере используется JSZip 3.10.1 через jsDelivr. Если библиотека недоступна, оригинальные файлы можно прикрепить, но извлечение структурированных сведений отключится; приложение покажет предупреждение.

## Безопасность

Режим импорта предназначен только для авторизованных редакторов. Перед загрузкой служебных данных обязательно проверьте Supabase Row Level Security и доступ к файлам `optp-files`. Текущий клиент формирует публичные ссылки на файлы; простой выбор подразделения **не является разграничением доступа**. Не загружайте материалы ограниченного доступа, пока Storage и RLS не настроены в соответствии с режимом защиты этих материалов.

Проверка предпросмотра не подтверждает точность оперативно-тактических сведений. После импорта необходимо сверить структурированные поля с первоисточниками перед использованием при пожаре.
