# ОПТП СКО — загрузка готовой папки Word и поэтажных планов

Выберите карточку пожарного подразделения, войдите как администратор и откройте «Загрузить папку с готовыми ОПТП». Можно выбрать общую папку с подпапками объектов **или** одну папку конкретного объекта, содержащую Word и поэтажные планы.

## Структура папки

```text
СПЧ-1/
  Театр кукол/
    ОПТП.docx
    Поэтажные планы/
      Этаж 1.jpg
      Этаж 2.pdf
  Школа №1/
    ОПТП.docx
    Поэтажные планы/
      Этаж 1.png
      Этаж 2.png
```

Приложение создаёт карточку по названию папки объекта, прикрепляет Word и PDF, распределяет этажные схемы по существующей вкладке «Поэтажные планы» с переключением и масштабированием. В рамках DOCX автоматически распознаёт только явно обозначенные поля: адрес, район, этажность, высоту, характеристики объекта, противопожарное водоснабжение, эвакуацию и силы и средства. Перед загрузкой откройте предварительный просмотр и проверьте значения; уже заполненные поля не изменяются. Неопознанные сведения остаются в оригинальном Word.

Форматы: DOCX для извлечения текста, DOC/PDF для хранения, PDF/JPG/PNG для поэтажных схем. Старые DOC, сканы, изображения текста и PDF с текстом не обрабатываются как структурированные сведения, но загружаются как документы/схемы. Не более 200 файлов за раз, до 20 МБ каждый.

Метка номера этажа определяется по имени файла («1 этаж», «Этаж 2»). Без номера файл остаётся схемой с пустым номером этажа. Для основной информации желательно использовать наименования разделов: «Общие сведения», «Водоснабжение», «Силы и средства», «Эвакуация».

## Однократная настройка

Если нужно, чтобы извлечённая информация о **силах и средствах** отображалась текстом в соответствующей вкладке, выполните SQL из `supabase/migrations/202611060003_forces_and_means.sql`. Без него оригинальный Word и остальные поддерживаемые поля загружаются, но текст этого раздела не сохраняется отдельно.

Для чтения DOCX в браузере используется JSZip 3.10.1 через jsDelivr. Если библиотека недоступна, оригинальные файлы можно прикрепить, но извлечение структурированных сведений отключится; приложение покажет предупреждение.

## Безопасность

Режим импорта предназначен только для авторизованных редакторов. Перед загрузкой служебных данных обязательно проверьте Supabase Row Level Security и доступ к файлам `optp-files`. Текущий клиент формирует публичные ссылки на файлы; простой выбор подразделения **не является разграничением доступа**. Не загружайте материалы ограниченного доступа, пока Storage и RLS не настроены в соответствии с режимом защиты этих материалов.

Проверка предпросмотра не подтверждает точность оперативно-тактических сведений. После импорта необходимо сверить структурированные поля с первоисточниками перед использованием при пожаре.

## Планы крупных производственных объектов

Вкладка **«Поэтажные планы»** хранит также схемы подвала, цокольного этажа, чердака, мансарды, генплан территории и технологические схемы зерносушилок, элеваторов, силосов, конвейеров и другого оборудования. Они хранятся в существующей таблице `optp_floor_plans`. Для схем без этажа поле `floor_number` остаётся `NULL`; название сохраняется, а в просмотрщике отображается вместо «Этаж N». Для подвала, помеченного числом `-1`, отображается название, а не «Этаж -1». В интерфейсе эти материалы сгруппированы отдельно от обычных этажей. Схемы водоснабжения остаются во вкладке «Водоснабжение».

При загрузке папки схема (PDF, JPG, PNG) определяется по названию файла или подпапки: `Генплан.pdf`, `Подвал.jpg`, `Чердак.png`, `Схема зерносушилки.pdf`, `Чертеж силоса.png`, а также по типовым техническим названиям. Обычные фотографии без признаков схемы не загружаются автоматически. Администратор также может вручную выбрать тип **«Генплан / технологическая схема»** и назначить понятное название.

Внимание: автоматическая классификация по имени файла не гарантирует правильного определения. Проверьте предварительный просмотр перед импортом и полноту схем объекта после загрузки.

## Обновлённая вкладка «Схемы»

В карточке объекта вкладка **«Схемы»** заменяет «Поэтажные планы». В ней отображаются все имеющиеся в `optp_floor_plans` планы этажей, генпланы, чертежи зерносушилок, элеваторов, подвалов, чердаков и другие графические файлы. Существующие записи не перемещаются и не удаляются.

**Водоснабжение остаётся отдельной вкладкой:** схемы гидрантов и водоисточников по-прежнему хранятся в `optp_documents` с каталогом `/water/` и не отображаются среди общих схем.

При массовой загрузке объекта или папки с объектами:
- DOC/DOCX и явно обозначенные текстовые PDF (например, ОПТП.pdf, Инструкция.pdf) остаются документами;
- остальные JPG/PNG/PDF, кроме схем водоснабжения, попадают в «Схемы»;
- вложенные папки сооружений сохраняются в заголовке: `Зерносушилка №1 / Этаж 1` и `Зерносушилка №2 / Этаж 1` — это разные схемы;
- типовые названия папок «Схемы», «Поэтажные планы», «Документы» в начале пути скрываются из заголовков, чтобы не дублировать уже сохранённые схемы.

Дополнительно в карточке объекта во вкладке «Схемы» доступна кнопка **«Загрузить папку со схемами»**. Она прикрепляет все PDF/JPG/PNG выбранной папки непосредственно к текущему объекту, не создавая новых объектов. Файлы из вложенной папки «Водоснабжение» направляются в водоснабжение. При загрузке показывается подтверждение количества схем, пропущенных файлов и ошибок; неоднозначное содержимое пользователь проверяет перед подтверждением. До 200 файлов за один раз, не более 20 МБ каждый. Изображения внутри Word-файлов не извлекаются: Word остаётся документом.

Права доступа к Supabase Storage должны быть проверены перед загрузкой любых служебных планов.
